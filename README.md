# Video hosting

Видео доступно напрямую по ссылке:

`https://raw.githubusercontent.com/yavaa-hub/test_video/main/video.mp4`

Для просмотра в плеере включите GitHub Pages: **Settings → Pages → Deploy from a branch → main / root**.
После публикации страница будет доступна по адресу:

`https://yavaa-hub.github.io/test_video/`

Пример использования:

```html
<video controls preload="metadata" src="https://raw.githubusercontent.com/yavaa-hub/test_video/main/video.mp4"></video>
```
